# Loon-Hub

自用及精选的 Loon 插件合集 · 一键安装 · 纯净规则。

## 快速安装

在 Loon 中打开：配置 → 插件 → 右上角  → 从 URL 添加，粘贴下方对应的 Raw 或 CDN 链接。

| 插件 | 说明 | Raw 链接 | CDN 链接 |
| :--- | :--- | :---: | :---: |
| **YouTube 去广告增强版** | 12 项参数配置 + 首页补强 + 字幕/歌词翻译 | [链接](https://raw.githubusercontent.com/your98k/Loon-Hub/main/Loon/YouTube-ADBlock-Enhanced.plugin) | [链接](https://cdn.jsdelivr.net/gh/your98k/Loon-Hub@main/Loon/YouTube-ADBlock-Enhanced.plugin) |
| **红果短剧去广告** | 拦截短剧开屏与信息流广告 | [链接](https://raw.githubusercontent.com/your98k/Loon-Hub/main/Loon/HongGuo.plugin) | [链接](https://cdn.jsdelivr.net/gh/your98k/Loon-Hub@main/Loon/HongGuo.plugin) |
| **虎扑去广告** | 本地 Mock 精简版，拦截 getOther 广告接口 | [链接](https://raw.githubusercontent.com/your98k/Loon-Hub/main/Loon/HuPu.plugin) | [链接](https://cdn.jsdelivr.net/gh/your98k/Loon-Hub@main/Loon/HuPu.plugin) |
| **Telegram 外链跳转** | 自动跳转 Telegram 客户端打开频道与代理等 | [链接](https://raw.githubusercontent.com/your98k/Loon-Hub/main/Loon/Telegram%E5%A4%96%E9%93%BE%E8%B7%B3%E8%BD%AC.plugin) | [链接](https://cdn.jsdelivr.net/gh/your98k/Loon-Hub@main/Loon/Telegram%E5%A4%96%E9%93%BE%E8%B7%B3%E8%BD%AC.plugin) |

## 说明

- 插件规则仅供个人学习交流与网络调试测试使用；
- 涉及 MitM 解密的插件，请确保已在 Loon 证书管理中安装 CA 证书并在 iOS 系统证书信任设置中信任。
